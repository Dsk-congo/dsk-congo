DSK CONGO V14 — ID SÉCURISÉS

Format final des ID :

Membre :
DSK-M-AAAAMM-XXXXXX-NP
Exemple :
DSK-M-202606-583714-MD

Admin :
DSK-A-AAAAMM-XXXXXX-NP-AD
Exemple :
DSK-A-202606-583714-MD-AD

Super Admin :
DSK-SA-AAAAMM-XXXXXX-NP-SupAd
Exemple :
DSK-SA-202606-583714-MD-SupAd

Explication :
- AAAAMM = année + mois de création
- XXXXXX = numéro aléatoire automatique
- NP = première lettre du nom + première lettre du prénom
- AD = Administrateur
- SupAd = Super Administrateur
